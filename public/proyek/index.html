Sistem Sekolah & Komunitas

1. Sistem Absensi Siswa per Mata Pelajaran

Dipakai aktif

Karena sekolah menerapkan sistem boarding school, orang tua di rumah sering tidak mengetahui apakah anaknya masuk di setiap jam pelajaran atau berhalangan di asrama.

Saya membangun aplikasi web absensi cepat di mana guru cukup memilih kelas, mata pelajaran, dan status kehadiran siswa (Hadir, Terlambat, Izin, Sakit, atau Alpa). Setelah disimpan ke database, sistem otomatis menyusun teks ringkasan siap kirim ke grup WhatsApp guru dan diteruskan wali kelas ke grup wali murid.

Lihat contoh format laporan WhatsApp (data contoh)

*Guru:* Yusuf Habib Alfatha, S.Kom., Gr.

* Ahmad Fauzan

Pengguna & Portal
SMP & SMA Budi Utomo Boarding School Tarakan (bubstarakan.com)
Teknologi
React.js & Headless WordPress API
Catatan Lapangan
Fitur tambahan seperti tugas kelas mirip classroom sempat dibuat, namun saya matikan karena guru ternyata lebih membutuhkan kecepatan pencatatan absen dan transparansi ke WhatsApp.

2. Sistem Presensi Guru Berbasis Lokasi GPS

Dipakai aktif

Untuk membantu sekolah memverifikasi kehadiran guru secara akurat, saya membuat modul presensi satu halaman yang terhubung langsung ke portal absensi sekolah.

Guru memilih nama, status posisi (Sekolah, Dinas Luar, atau Lainnya), keterangan opsional, lalu menekan validasi lokasi. Sistem menghitung jarak koordinat GPS perangkat terhadap titik koordinat sekolah dalam satuan meter dan menghasilkan format laporan siap kirim ke grup WhatsApp guru.

Lihat contoh format presensi guru (data contoh) 
📍 *ABSENSI GURU*

*Nama*    : Budi Santoso, S.Pd.
*Tanggal* : Selasa, 27 Januari 2026
*Jam*     : 07:12
*Posisi*  : Sekolah
*Jarak*   : 42.15 meter
*Status*  : VALID✅

*Keterangan:*
Mengisi jam pertama di kelas 8A
Pengguna & Portal
Guru SMP Budi Utomo Boarding School (bubstarakan.com)
Teknologi
React.js, Geolocation API, PHP Vanilla API
Catatan Lapangan
Fitur presensi harian sudah berjalan, sementara modul rekap otomatis bulanan masih menunggu jadwal pengembangan. Pelajaran pentingnya: merilis fitur baru ke guru tetap perlu sesi pendampingan singkat agar adopsinya merata.

3. Portal Absensi Pondok & Rencana Integrasi RFID

Uji coba & roadmap

Portal utama sekolah (bubstarakan.com) sedang dikembangkan menjadi satu pintu yang menggabungkan absensi mapel SMP/SMA, akses ke SPP, absensi pengajian pondok, dan absensi apel pondok.

Modul pengajian dan apel pondok saat ini berada pada tahap uji coba lapangan, dengan rencana lanjutan mengintegrasikan pembaca kartu RFID / smart tag ID pada kartu santri yang perangkat fisiknya sudah tersedia.

Lingkup
Sekolah & Pondok Budi Utomo Tarakan
Status
Pengembangan & pengujian berkala

4. Sistem Manajemen SPP & Cetak Kwitansi

Terbangun

Dibangun dalam waktu dua bulan untuk mengelola tagihan SPP siswa dengan skema pembayaran bertahap (cicilan) hingga status otomatis berubah menjadi lunas, berbagi database siswa dengan sistem absensi utama.

Dilengkapi halaman pemilihan riwayat pembayaran untuk mencetak bukti kwitansi langsung dari browser lengkap dengan kolom nama bendahara, nama orang tua, nomor surat, dan tanggal.

Subdomain Sistem
spp.bubstarakan.com
Teknologi
Vue.js & PHP Vanilla API
Catatan Lapangan
Sistem jarang dipakai rutin karena bendahara sudah nyaman dengan pencatatan Excel dan kwitansi tulis tangan. Dari sini saya belajar bahwa memahami alur kerja pengguna jauh lebih penting daripada sekadar menerjemahkan permintaan fitur.

6. Sistem Database Generus PPG Kota Tarakan

Dipakai aktif

Dibangun untuk membantu pengurus PPG Daerah Kota Tarakan memiliki data demografi generasi muda (generus) yang terstruktur di 2 desa dan 22 kelompok jamaah.

Sistem menyediakan akun multi-login per kelompok untuk mengelola data generus dan berhasil mengumpulkan sekitar 950 data dalam dua bulan pertama.

Domain Sistem
database.ppgtarakan.com
Teknologi
React.js, Headless WordPress API, MySQL
Catatan Lapangan
Setelah dua bulan awal, pembaruan data dari tiap kelompok mulai jarang dilakukan. Pelajarannya: sebelum mendigitalkan pendataan organisasi, mekanisme pengumpulan dan pembaruan data secara rutin di lapangan harus disepakati dulu agar data digital tidak tertinggal dari kondisi nyata.

7. Sistem Presensi Barcode Acara CAI (2024 & 2025)

Acara tahunan

Sistem pemindaian barcode pada kartu peserta (Co-Card) untuk mencatat kehadiran peserta pengajian Cinta Alam Indonesia (4 hari berturut-turut, sesi pagi, siang, dan malam) di Masjid Almukminun Tarakan.

Pada tahun 2024, sistem dibuat dalam 3 hari menggunakan server lokal di laptop lewat jaringan Wi-Fi masjid dengan ekspor data ke spreadsheet untuk rekap tiap akhir sesi. Pada tahun 2025, sistem ditingkatkan menjadi versi online (staging.ppgtarakan.com) dengan tambahan papan peringkat 10 peserta tercepat hadir di setiap sesi.

Penyelenggara
LDII / PPG Kota Tarakan
Teknologi
React.js, Node.js (2024), Headless WordPress API (2025)

8. Absensi Pagi & Kartu Pelajar Barcode TK/SDIT Insan Luhur

Arsip 2024–2025

Proyek absensi sekolah pertama yang saya bangun dari diskusi kebutuhan untuk mencegah salah paham antara pihak sekolah dan orang tua mengenai status keterlambatan siswa di pagi hari.

Saya membuat plugin khusus dan skema database kustom di atas WordPress tanpa plugin pihak ketiga: guru memindai barcode pada kartu pelajar (otomatis menandai terlambat jika lewat pukul 07.00), dan orang tua dapat memindai kartu yang sama untuk melihat riwayat kehadiran anaknya.

Teknologi
WordPress Custom Plugin & Custom Database Schema
Status
Tidak lagi aktif (sdit.web.id telah dihapus)
Nilai Penting
Meski tidak berlanjut dipakai di sekolah tersebut dan komunikasi awal kurang matang, konsep transparansi kehadiran ke orang tua inilah yang menjadi fondasi seluruh sistem absensi sekolah saya berikutnya.
